GROOVY DROP은 MOVABLE! (무버블!) 이용자의 개인정보를 존중합니다. 이 방침은 현재 확인한 Android 앱의 기능과 Google 광고·동의 SDK 구성을 기준으로 개인정보 처리 내용을 설명합니다.

1. 앱과 문의처

  • 앱 이름: MOVABLE! (무버블!)
  • Android 패키지명: com.groovydrop.movable
  • 개발자 표시명: GROOVY DROP
  • 개인정보 관련 문의: groovydrop.dev@gmail.com
  • 방침 최종 갱신일: 2026년 11월 10일

앱은 Capacitor 기반 Android 블록 퍼즐 게임입니다. 자체 회원가입, 로그인 또는 자체 온라인 순위 서버를 제공하지 않습니다. GROOVY DROP은 개발자 표시명이며, 이 방침이 법인 설립이나 상표 등록 사실을 나타내지는 않습니다.

2. 게임 기록과 설정의 로컬 저장

게임판, 제공 블록, 점수와 최고 점수, 콤보, Move, 테마, 이어하기 사용 및 보상 반영 상태, 튜토리얼 완료 여부, 광고 노출 빈도와 음악·효과음·진동·조작 손·화면 효과 설정 등을 기기에 저장합니다. 이는 게임 진행 복원, 기록 표시, 설정 유지 및 중복 보상 방지에 사용됩니다.

주로 WebView의 localStorage를 이용하며, 중복 보상을 방지하기 위한 보상 요청 식별자는 Android SharedPreferences에도 저장합니다. 네이티브 보상 영수증은 정상 반영을 확인한 뒤 삭제하며, 게임 진행에 포함된 보상 반영 상태는 별도로 기기에 남을 수 있습니다.

현재 앱에는 이 게임 저장 데이터를 개발자 서버로 업로드하거나 계정 간에 동기화하는 기능이 없습니다. 광고 SDK가 처리하는 앱·광고 상호작용 정보는 로컬 게임 저장 데이터와 구분됩니다.

3. 광고 SDK가 처리할 수 있는 정보와 목적

앱에는 Google Mobile Ads SDK 24.7.0이 포함되어 있으며 하단 배너, 전면 광고 및 사용자가 선택하여 시청하는 이어하기 보상형 광고에 사용됩니다. 현재 프로젝트의 기본 Android 광고 설정은 Google 공식 테스트 광고 ID를 사용합니다. 테스트 광고나 광고 미표시가 모든 SDK 통신·데이터 처리의 부재를 의미하지는 않습니다.

Google의 광고 서비스는 광고 제공·측정, 분석, 부정행위 방지 및 보안 등의 목적으로 다음 정보를 처리할 수 있습니다.

  • IP 주소와 이를 바탕으로 추정할 수 있는 대략적인 위치
  • 앱 실행, 광고 탭, 영상 조회 등 앱·광고 상호작용 정보
  • 실행 시간, 멈춤 비율, 에너지 사용 등 앱과 SDK의 진단 정보
  • Android 광고 ID, App Set ID 등 기기 또는 기타 식별자 및 해당하는 경우 기기 로그인 계정 관련 식별자

실제 처리 범위는 기기, SDK, 동의 상태, 광고 제공 방식 및 광고 파트너 설정에 따라 달라질 수 있습니다. 개발자는 게임판이나 점수·설정 전체를 광고 요청의 별도 사용자 데이터로 추가하지 않습니다.

전면 광고는 실제 표시 전에 미리 로드될 수 있습니다. 보상형 광고 시청을 선택하지 않았다는 이유만으로 배너·전면 광고 등 다른 SDK 요청이 발생하지 않는 것은 아닙니다.

관련 설명: Google Mobile Ads 데이터 공개 안내. 이 공식 페이지는 최신 SDK를 설명하므로 고정 버전의 모든 세부 동작에 대한 별도 보증으로 해석하지 않습니다.

4. UMP 동의 관리와 선택권

Google User Messaging Platform(UMP) SDK 3.2.0을 사용하여 동의 정보를 갱신하고 해당되는 경우 개인정보 동의 양식과 개인정보 옵션을 제공합니다. 앱은 UMP가 광고 요청을 허용하는 상태인지 확인한 뒤 광고 SDK를 초기화하고 광고를 요청합니다.

동의 관리 과정에서는 앱·SDK 버전, 앱 식별 정보, 기기 모델과 Android 버전, 언어·화면 정보 및 저장된 동의 상태·선택 등 기술정보가 처리될 수 있습니다. UMP 3.2.0 자체는 광고 ID를 사용하지 않지만, 별도의 Google Mobile Ads SDK는 광고 ID 등을 처리할 수 있습니다.

개인정보 옵션이 요구되는 상태에서는 앱 메뉴의 해당 옵션에서 선택을 다시 확인하거나 변경할 수 있습니다. 동의 거부·변경이 기본 광고 제공, 측정, 보안 또는 규정 준수에 관련된 모든 처리가 중단된다는 의미는 아닙니다.

Android 설정에서 광고 ID를 삭제·재설정하거나 관련 선택을 변경할 수 있습니다. 제공 기능과 메뉴 이름은 기기와 Android 버전에 따라 다릅니다. 이 조작이 모든 식별자 또는 이미 보관된 광고 데이터까지 삭제하는 것은 아닙니다.

추가 안내: Google 광고 선택, UMP 동의 관리.

5. Google 및 제3자 제공·처리

광고와 동의 기능을 위해 Google 서비스가 사용되며 관련 기술정보가 Google에 전송될 수 있습니다. 실제 광고 서비스 구성에 따라 Google과 광고 기술 제공업체가 각자의 역할 및 정책에 따라 정보를 처리할 수 있습니다. 모든 Google 광고 처리를 단순한 처리 대행으로 단정하거나 제3자 처리가 전혀 없다고 설명하지 않습니다.

현재 코드에는 별도의 자체 분석 서버, 독립 Firebase Analytics·Crashlytics 또는 제3자 광고 중개 SDK가 확인되지 않았습니다. 운영 AdMob 광고 파트너 목록이나 서비스 구성이 변경되는 경우 그 처리 내용과 방침을 다시 검토합니다.

Google 등의 서비스는 국외 서버에서 정보를 처리할 수 있습니다. 서비스별 수신자의 법적 명칭, 제공·위탁 관계, 국외 이전 국가·시점·방법·근거 및 보유기간은 실제 계약과 운영 설정에 따라 확인해야 합니다. 현재 문서에서 확인되지 않은 세부 조건을 확정된 사실로 제시하지 않습니다.

관련 정책: Google 개인정보처리방침, Google 파트너 서비스를 사용하는 앱·사이트에서의 정보 처리.

6. 점수 공유

사용자가 점수 공유를 선택하면 앱 이름과 실제 점수 등이 포함된 텍스트를 Android 기본 공유 화면에 전달합니다. 사용자가 대상 앱을 직접 선택하며 이후의 처리에는 선택한 서비스의 정책이 적용됩니다.

앱이 주소록을 읽거나 사용자 선택 없이 메시지를 전송하지는 않습니다. 공유 화면을 닫았다는 사실만으로 전달 성공 여부를 확정하지 않습니다. 현재 설정에서는 스토어 공개 출시를 확인하기 전까지 다운로드 링크를 공유 메시지에 포함하지 않습니다.

7. 보관과 삭제

로컬 게임 기록과 설정은 변경·덮어쓰기되거나 사용자가 앱 데이터를 삭제할 때까지 기기에 유지될 수 있습니다. 새 게임을 시작하는 것만으로 최고 점수와 모든 설정이 삭제되지는 않습니다.

기기 내 앱 데이터는 Android 설정의 ‘앱 → MOVABLE! → 저장공간 → 데이터 삭제’에 해당하는 기능으로 삭제할 수 있습니다. 앱 삭제 시에도 일반적으로 기기 내 앱 데이터가 제거됩니다. 메뉴와 실제 동작은 기기에 따라 달라질 수 있습니다.

현재 앱 설정은 Android 백업을 허용합니다. 운영체제·기기·사용자 설정이 지원하는 범위에서 데이터가 백업되거나 기기 이전·재설치 시 복원될 수 있습니다. 기기 내 데이터 삭제가 백업 사본의 즉시 삭제를 보장하지는 않으며, 백업의 보관·삭제에는 해당 플랫폼의 정책과 설정이 적용됩니다.

현재 앱에는 Google 또는 광고 파트너가 보관한 데이터를 직접 조회·삭제하거나 삭제 요청을 자동 처리하는 기능이 없습니다. 광고 ID 삭제, 로컬 데이터 삭제 또는 동의 변경이 이미 보관된 서버 데이터의 삭제 완료를 뜻하지 않습니다.

광고·동의 서비스의 보관과 삭제는 해당 서비스의 목적, 정책, 계약 및 적용 법률에 따릅니다. 서비스별 정확한 보유기간과 개별 삭제 처리 결과는 개발자가 확인하지 못한 부분이 있으며, 모든 정보를 일정 기간 이내 자동 삭제한다고 보장하지 않습니다.

8. 보안

Google Mobile Ads의 공식 안내는 수집 정보의 전송에 TLS 암호화를 사용한다고 설명합니다. 현재 UMP 3.2.0의 동의 요청도 HTTPS를 사용하며, 앱 자체에는 게임 저장 데이터를 평문으로 업로드하는 기능이 없습니다.

전송 중 암호화는 기기에 저장된 모든 데이터의 암호화, 종단간 암호화 또는 모든 보안 위험 제거를 의미하지 않습니다.

9. 대상 연령

MOVABLE!의 의도한 대상은 13~15세, 16~17세 및 18세 이상 일반 이용자입니다. 13세 미만 아동을 주요 타깃에 포함하지 않으며 아동을 특별히 대상으로 하는 콘텐츠나 홍보를 계획하지 않습니다.

13세 이상이라는 기준이 모든 국가에서의 개인정보 처리 동의 가능 연령을 뜻하지는 않습니다. 국가별 미성년자·보호자 권리와 동의·광고 처리 요건은 별도로 검토해야 합니다. 이 방침이 자동 연령 확인이나 보호자 동의 기능을 제공한다는 의미는 아닙니다.

운영자가 직접 처리할 수 없는 Google·외부 서비스의 데이터에는 해당 서비스의 절차가 적용될 수 있습니다. 문의 이메일 제공만으로 앱 내 데이터 삭제 기능이나 외부 서비스의 삭제 완료를 보장하지 않습니다. 적용 국가별 권리 행사 절차·처리 기한과 실제 운영자의 법적 정보 등 추가 확인이 필요한 항목은 확인 후 이 방침에 반영합니다.

앱 기능, 광고 구성 또는 개인정보 처리 방식이 변경되는 경우 이 페이지의 내용과 갱신일을 수정합니다. 중요한 변경에 대한 고지는 적용 법률과 실제 운영 절차에 맞춰 제공합니다.
