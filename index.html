Groovy Drop

Grid by Day 개인정보처리방침

시행일: 2026년 11월 9일 · 개발자: Groovy Drop

Groovy Drop(이하 “개발자”)은 Grid by Day(이하 “앱”) 이용자의 개인정보를 존중합니다. 본 방침은 광고 및 회원가입 기능이 없는 현재 앱 버전을 기준으로 작성되었습니다.

1. 처리하는 정보와 이용 목적

앱은 사용자가 입력한 근무 유형과 반복 패턴, 날짜별 일정·연차 기록, 근무시간, 급여·수당 기록, 환경설정 및 알림 설정을 기기 내부에 저장합니다. 이 정보는 달력·홈 화면 위젯·급여 기록의 표시, 설정 유지 및 요청한 알림 제공에 이용됩니다.

현재 앱은 회원가입 및 자체 서버를 통한 일정·급여 동기화를 제공하지 않습니다. 기본 이용을 위해 이름, 전화번호, 주소 또는 위치정보를 입력하도록 요구하지 않습니다.

2. 저장 위치 및 외부 전송

사용자가 입력한 일정·급여·설정 데이터는 기기의 앱 저장 영역에 보관됩니다. 앱은 현재 자체 서버로 해당 데이터를 업로드하지 않습니다. 위젯과 알림은 기기 내 기능을 이용합니다.

사용자가 백업을 선택할 경우 일정·급여·설정을 포함한 JSON 파일이 생성되며, Android 공유 기능으로 파일의 저장 위치나 공유 대상을 선택할 수 있습니다. 해당 서비스의 개인정보 처리에는 각 서비스 정책이 적용됩니다. 백업 파일에 급여 정보 등이 암호화되지 않은 형태로 포함될 수 있으므로 안전하게 보관해 주세요.

3. 기기 권한

근무 알림 사용 시 Android 알림 권한을 요청할 수 있습니다. 권한은 기기 설정에서 변경할 수 있습니다. 백업 내보내기·복원 시 Android 공유 기능과 파일 선택기를 이용합니다. 실제 출시 번들에 포함되는 모든 권한은 출시 전 최종 확인합니다.

4. 제3자 제공 및 광고

현재 앱은 광고 SDK를 이용한 맞춤 광고나 광고 식별자 수집 기능을 포함하지 않습니다. 사용자가 입력한 일정·급여 데이터를 광고 사업자에게 제공하지 않습니다. 추후 광고, 결제, 분석 또는 오류 보고 서비스를 도입할 경우 실제 처리 방식에 맞춰 본 방침 및 Google Play 데이터 보안 정보를 수정합니다.

5. 보유 기간 및 삭제

데이터는 앱을 사용하는 동안 기기 내부에 보관됩니다. 앱을 제거하거나 해당 앱 데이터를 삭제하면 기기 내 앱 저장 영역의 기록이 삭제됩니다. 사용자가 별도로 내보내 다른 앱이나 클라우드 등에 저장한 백업 파일은 자동 삭제되지 않으므로 해당 저장 위치에서 직접 삭제해야 합니다.

6. 정보 보호

앱은 Android 앱별 저장 영역을 이용합니다. 급여 화면 잠금은 화면 접근을 제한하는 기능으로, 저장된 모든 급여 정보나 JSON 백업 파일의 암호화를 보장하지는 않습니다. 기기 화면 잠금과 안전한 백업 파일 보관을 권장합니다.

7. 아동의 개인정보

앱은 교대근무 일정 관리를 주된 목적으로 하며, 아동의 개인정보를 별도로 수집하는 기능은 제공하지 않습니다.

8. 방침 변경

앱 기능 및 개인정보 처리 방식에 변경이 있을 경우 이 페이지의 내용과 시행일을 갱신합니다.
